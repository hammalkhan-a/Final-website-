# Academy Class Management System

A Core PHP, Bootstrap 5, Vanilla JavaScript, and MySQL project for admissions, attendance, student search, fees, and results.

## Setup
1. Start Apache and MySQL from XAMPP.
2. Open http://localhost/aiweb/install.php to create the database schema and seed data.
3. Open http://localhost/aiweb/ to use the public pages.
